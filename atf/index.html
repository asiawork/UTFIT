ไฟล์ Model Performance

ไฟล์อยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ถูกส่งขึ้นเว็บหรือเก็บใน GitHub

ดาวน์โหลดจาก Tableau

  1. เปิด Tableau · Model Performance แล้วเลือกทุกโมเดล
  2. กด Download → Data แล้วดาวน์โหลดเป็น CSV
  3. ลากไฟล์มาวางในกรอบ หรือกดเพื่อเลือกไฟล์
