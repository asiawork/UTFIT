อัปโหลดข้อมูล Auto Top Funds

ถ้าอัปโหลดไว้ในหน้า Auto Top Funds แล้วไม่ต้องอัปโหลดซ้ำ ไฟล์ที่อัปโหลดที่นี่ก็ใช้ร่วมกับเครื่องมืออื่นได้เหมือนกัน

  1. เปิด Tableau · Model Performance
  2. เลือกโมเดลที่ต้องการ เช่น FIXEDSP หรือเลือกทุกโมเดล
  3. กด (Download) → Data
  4. กดปุ่มด้านล่าง แล้วเลือกไฟล์ที่ดาวน์โหลดมา

หมายเหตุ: ข้อมูลอยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ถูกส่งขึ้นเว็บ ใช้ร่วมกับทุกเครื่องมือในหมวด Auto Top Funds จำไว้จนกว่าจะอัปโหลดไฟล์ใหม่หรือกดล้าง

ข้อมูลกองทุน

ข้อมูล NAV และข้อมูลกองทุนรวมจาก SEC Open API (สำนักงาน ก.ล.ต.) · ผลตอบแทนคำนวณจาก NAV ต่อหน่วย ไม่รวมค่าธรรมเนียมซื้อขาย ผลการดำเนินงานในอดีตไม่ได้เป็นสิ่งยืนยันถึงผลการดำเนินงานในอนาคต · ข้อมูล Auto Top Funds ที่อัปโหลดไม่ถูกส่งขึ้นเว็บ อยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น

สร้างพอร์ตจำลอง

รวมกองทุนหรือโมเดล Auto Top Funds ตามสัดส่วนที่กำหนด แล้วแสดงเป็นอีกเส้นในกราฟ

ปรับสัดส่วนกลับ (rebalance)
กองทุน / โมเดลจำนวนเงินสัดส่วน

กราฟเส้นเริ่มซื้อตามสัดส่วนนี้ ณ วันแรกของช่วงที่เลือก · กราฟรายปีนับจากวันแรกที่ทุกกองในพอร์ตมี NAV · ไม่รวมค่าธรรมเนียมซื้อขาย · พอร์ตจำไว้ในเบราว์เซอร์เครื่องนี้ 1 วัน
